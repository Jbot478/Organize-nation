# Team Go

Shared task manager for a small team with light gamification.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy environment file and fill in Supabase values:
   ```bash
   cp .env.example .env
   ```
3. Set:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Start dev server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
